# 📊 Student Result Analysis System

A web-based **Student Result Analysis System** built using **Python and Flask**. The project allows users to upload student result data and analyze academic performance through an interactive dashboard.

## 🚀 Features

* 📁 Upload student result data
* 📊 Analyze student performance
* 📈 Interactive charts and visualizations
* 🎓 Student-wise result analysis
* 📚 Subject-wise performance analysis
* 🏆 Identify top-performing students
* ✅ Pass/Fail analysis
* 💻 Simple and user-friendly web interface

## 🛠️ Technologies Used

* **Python**
* **Flask**
* **Pandas**
* **Plotly**
* **HTML**
* **CSS**
* **Bootstrap**
* **Microsoft Excel**

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/SamarthKoti/Student-Result-Analysis-System-using-EXCEL.git
```

### 2. Navigate to the project folder

```bash
cd Student-Result-Analysis-System-using-EXCEL
```

### 3. Install the required dependencies

```bash
pip install flask pandas plotly openpyxl
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in your browser

```text
http://127.0.0.1:5000/
```

## 📊 Project Overview

The system is designed to simplify the analysis of student academic results. Instead of manually analyzing large amounts of result data, the application processes the data and presents meaningful insights through tables, statistics, and visualizations.

## 🎯 Objective

The main objective of this project is to develop a simple and interactive platform for analyzing student results and understanding academic performance using **Python, Flask, Pandas, and data visualization techniques**.
